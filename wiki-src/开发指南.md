## 架构总览

四层结构，**越往下越稳定**：

```
core/     上游 CircuitJS1 源码（只读，pinned commit）
  ↑ 覆盖/影子
cover/    覆盖层：同名文件影子替换 + 新增文件 + 插件宿主 + 启动编排
  ↑ 运行期加载
plugins/  插件（动态 import，带 manifest / 权限 / 生命周期）
  ↑ 复用
packages/ 可复用库：netlist（网表）· plugin-api（插件契约）· mcp（AI 接口）
  ↑
tools/    App 层 CLI：ext doctor/dev/build/serve/cover/plugin/netlist/mcp
```

**铁律**：`core/` 永远只读。要改上游行为，一律在 `cover/` 里做覆盖。

## 构建与调试

```bash
node tools/ext.mjs doctor     # 环境自检（Node 版本、core.lock、manifest 完整性、语料）
node tools/ext.mjs build      # tsc(core) + tsc(cover) + vite build → dist/
node tools/ext.mjs dev        # Vite dev server（热更新，默认 5174）
node tools/ext.mjs serve      # 静态服务 dist/（默认 8080）
node tools/ext.mjs test       # 上游 vitest 单测
```

### 浏览器里调试

打开 `http://127.0.0.1:5174/circuitjs.html`，控制台里：

```js
window.ExtCircuitJS          // 总入口：api / plugins / events / app
window.ExtCircuitJS.app      // 上游 CirSim 实例（elmList、sim 等）
window.ExtCircuitJS.api      // 扩展 API
window.ExtCircuitJS.plugins  // 插件宿主
```

## 覆盖层（cover）机制

`coverOverlay.mjs` 在 Vite 解析阶段做**路径影子**：

| core 中存在 | cover 中存在 | 结果 |
|---|---|---|
| ✅ | ✅ | 解析到 cover 版本（覆盖） |
| ❌ | ✅ | 解析到 cover 版本（新增） |
| ✅ | ❌ | 走 core |

`cover/cover.manifest.json` 记录每个覆盖条目：`upstreamPath`、`localPath`、`kind`（overridden/added）、
`forkPointBlob`（fork 时的上游文件 hash）、`anchors`（上游必须存在的文本锚点，用于同步时校验）。

```bash
node tools/ext.mjs cover status    # 每个覆盖条目的状态
node tools/ext.mjs cover scan --json build/cover-scan.json
node tools/ext.mjs cover sync-drill # 假上游演练（验证同步判定逻辑）
```

状态含义：`local-only`（只在本地改了）、`clean`、`upstream-changed`（上游变了、本地没变 → 可直接 rebase）、
`both-changed`（两边都变 → 必须人工）、`orphan`（上游文件消失）、`anchor-broken`（锚点找不到）。

> ⚠️ **不要给 cover/ts 里新建与 core 同名的文件**，除非你打算完整镜像它——否则会整文件影子掉 core，内部 import 全部命中你的版本。

## 网表子系统

`packages/netlist/src/`：

| 文件 | 职责 |
|---|---|
| `index.ts` | `exportNetlist`（引擎 → 语义 JSON）、`applyOps`（set/delete/probe/add） |
| `ids.ts` | 稳定 id（WeakMap，`e1..eN`，全新电路重置） |
| `compact.ts` | 紧凑编码/解码（短键 + 类型索引，约 0.26× XML） |
| `compile.ts` | 网表 → 电路编译器（含拓扑硬闸） |
| `geom.ts` | 自动布局 + A* 绕障布线 |
| `place.ts` | 增量放置（导线分裂 + 正交补线 + 自校验回滚） |
| `registry.json` | 元件描述表（255 类），由 `registry-gen.mjs` 从 core 源码生成 |

```bash
node tools/ext.mjs netlist registry   # 从 core/ts 重新生成 registry.json
node tools/ext.mjs netlist bench      # 紧凑编码体积基准（需 dev server）
```

**核心设计**：真源是引擎对象（`app.elmList` + `app.sim.nodeList`），**不解析 XML 文本**；坐标默认不输出。

## MCP 子系统

`packages/mcp/src/`：

| 文件 | 职责 |
|---|---|
| `stdio.ts` | MCP 协议层（stdin/stdout JSON-RPC） |
| `server.ts` | 服务器主循环 |
| `backend.ts` | 懒启动后端（dev server + 浏览器） |
| `session.ts` | 会话式 RPC（open/load/step/measure/export/close） |
| `bridge-client.ts` | 环回 WebSocket 客户端（零依赖 RFC6455） |
| `tools.ts` | 工具集（attach 模式） |
| `cli.mjs` | `ext mcp` 入口 |

对应页面侧：`cover/ts/ExtMcpBridge.ts`（挂在 `window.ExtCircuitJS.mcp`）。

详见 `docs/mcp.md`。

## 测试体系

全部在 `tests/contract/`，两类：

| 类型 | 命名 | 运行环境 |
|---|---|---|
| Node 契约 | `*.test.mjs`（无 `.browser`） | 纯 Node（`node --test`） |
| 浏览器契约 | `*.browser.mjs` / `*.browser.test.mjs` | 真实 Chromium + dev server |

```bash
# Node 侧（CI 跑这些）
node --test tests/contract/*.test.mjs

# 浏览器侧（需 dev server 在 5174 + 本机 Chrome）
node tools/ext.mjs dev --port 5174          # 终端 1
node tests/contract/boot.browser.mjs        # 终端 2

# 环境变量（默认指向开发机路径，可覆盖）
EXT_PW_CORE=/path/to/playwright-core/index.mjs
EXT_CHROME=/path/to/chrome
EXC_BASE=http://127.0.0.1:5174
```

### 写测试要用到的基座

- **Node 加载 TS**：`tests/contract/helpers/ts-resolve.mjs`（register 后动态 import `.ts`，自动补扩展名与 cover→core 镜像）
- **激活默认禁用的示例插件**：`tests/contract/helpers/activate-plugins.mjs`
- **确定性步进**（拿可复现数值）：`analyzeCircuit() → preStampAndStampCircuit() → runCircuit()`，配合冻结 `Date.now`
  （见 `netlist-g2.browser.mjs`）。只调 `preStampCircuit` 会在 runCircuit 的 NaN 检查崩。

## CI

`.github/workflows/ci.yml`，双平台（Windows + Ubuntu）：

- **test job**：doctor / build / plugin lint / cover scan / Node 契约
- **browser job**：装 playwright-core + build（dist-site 要产物）+ 后台起 dev server + 串行跑全部浏览器契约

`.github/workflows/pages.yml` 在 main 上自动部署 `dist/` 到 GitHub Pages。

## 上游同步

当 `pfalstad/circuitjs1` 有新提交：

```bash
node tools/ext.mjs core sync          # 检查远端 HEAD 是否变化
git clone --filter=blob:none https://github.com/pfalstad/circuitjs1 build/upstream
node tools/ext.mjs cover scan --core build/upstream   # 看哪些覆盖条目受影响
# 按 scan 结果 rebase cover/，更新 core.lock.json 与 cover.manifest.json 的 forkPointBlob
```

`upstream-changed` 的条目可以直接重 fork；`both-changed` 必须人工合。

## 代码规范与约定

1. **`core/` 只读**。任何"必须改 core"的诉求先上报。
2. **验收命令是唯一裁判**：完成的标准是命令退出码/输出，不是"我觉得好了"。
3. **测试断言不许弱化换绿**；发现测试本身错了，记录并上报。
4. **禁止顺手重构**；计划外发现记到 `docs/handoffs/observations.md`。
5. **每张卡独立 commit**，不混无关文件。
6. Node 侧加载 TS 注意 **strip-only 模式不支持参数属性**（`constructor(private x)` 会报错），用显式字段。
7. 测试里引用仓库内模块**不要硬编码本机绝对路径**（CI 会 404），用 `import.meta.dirname` 推导。
