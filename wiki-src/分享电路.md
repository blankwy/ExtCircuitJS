# 分享电路

ExtCircuitJS 有三条分享路径，**从最轻到最完整**。选哪一个取决于"对方要做什么"。

| 方式 | 产物 | 对方需要什么 | 适合 |
|---|---|---|---|
| **① 分享链接** | 一个 URL（几百字符） | 只一个浏览器 | **最常用**：发链接就能看、能点 RUN 仿真、能拖滑块 |
| ② 分享页 | 1–2 KB 的 .html | 浏览器 + 能访问原站点 | IM 会截断长 URL 时 |
| ③ 单文件 HTML | 1.4 MB 的 .html | 只一个浏览器（完全离线） | 发文件给对方、内网/离线环境 |

---

## ① 分享链接（推荐）

### 在界面里

命令面板（`Shift` 双击）搜"**分享**"，三条命令：

| 命令 | 作用 |
|---|---|
| 分享：生成链接并复制 | 生成当前电路的链接，自动复制到剪贴板 |
| 分享：仅复制链接 | 同上，不弹提示条 |
| 分享：下载单 HTML（含电路） | 下载方式 ③ |

### 在命令行（不需要浏览器）

```bash
# 内置语料
node tools/ext.mjs share --circuit lrc

# 任意电路文本
node tools/ext.mjs share --text "r 100 100 300 100 0 1000"

# 电路文件
node tools/ext.mjs share --file my-circuit.txt

# 指定站点（默认 GitHub Pages）
node tools/ext.mjs share --circuit lrc --base https://example.com/ExtCircuitJS

# 顺便生成分享页（方式②）
node tools/ext.mjs share --circuit lrc --out build/share.html
```

**stdout 只有一行 URL**（诊断信息走 stderr），方便脚本/工具直接抓取：

```bash
URL=$(node tools/ext.mjs share --circuit lrc 2>/dev/null)
```

### 原理

URL 形如 `https://<站点>/circuitjs.html?ctz=<LZString 压缩的电路文本>`

- 上游既有的分享机制（"文件 → Export As Link"同款），本仓库只是做成一键 + 可脚本化
- `ctz` 是电路文本经 LZ 压缩 + URI 编码的结果，**全部信息都在 URL 里**，不需要服务端
- 页面启动时读 `?ctz` → 解压 → 载入电路 → 可直接仿真

**实测**：lrc 电路（441 字节）→ ctz 346 字符 → URL 约 404 字符；打开后自动载入 7 个元件、仿真自动运行。

### 长度注意

- **< 2000 字符**：几乎所有渠道都能完整传递
- **2000–8000**：部分 IM/邮件客户端可能截断
- **> 8000**：脚本会警告，建议改用方式②或③

复杂电路（几十个元件）的 URL 可能到几 KB。脚本会如实报告长度并在超阈值时提示。

## ② 分享页（URL 太长时的折中）

```bash
node tools/ext.mjs share --circuit lrc --out build/share.html
```

产出 1–2 KB 的 HTML，内部是 `<iframe src="<带 ctz 的 URL>">`。

- **优点**：文件极小，可当附件/贴进文档
- **缺点**：仍依赖原站点可达（脚本从原站加载）

---

## ③ 单文件 HTML（真离线）

```bash
node tools/ext.mjs build
node tools/ext.mjs bundle-single --out build/circuitjs-single.html
```

产出约 1.4 MB 的**单个 HTML**，把 JS/CSS/字体全内联。

- **双击即开**（`file://` 可运行，已实测）
- **零依赖**：不需要 Node、不需要网络、不需要原站点
- 可以塞进 skill、挂网盘、当附件发

**限制**（已实测，如实说明）：内置电路列表为空（需 fetch）、语言包不加载（显示英文）、Service Worker 不注册。核心绘制与仿真功能完全正常。

## 给 AI 助手 / 自动化工具的建议

**当用户问电路问题**，优先顺序：

1. **一句话能答** → 直接文字回答，别折腾
2. **需要看图/调参** → 用 MCP 跑仿真拿真实数值 + 生成 SVG 波形
3. **用户想自己动手试** → **生成分享链接**（`ext share`），一个 URL 就够，零门槛
4. **用户要离线/内网/存档** → 单文件 HTML

**从网表到分享链接的完整链路**（AI 可全自动完成）：

```
读网表 / 生成电路文本
  → node tools/ext.mjs share --text "<电路文本>"     （拿 URL）
  → 把 URL 给用户，或 node tools/ext.mjs share --out x.html  （出分享页）
```

如果电路是 AI 现造的（不是内置语料），用网表 → 电路编译器拿电路文本再分享：

```bash
# 网表 JSON → 电路文本（compile.ts 自动布局 + A* 布线）
node -e "..."   # 或通过 MCP 的 circuit.load_netlist + dumpCircuit
node tools/ext.mjs share --text "<得到的电路文本>"
```

## 常见问题

### 链接打开是空白/默认电路？

- 检查 `ctz` 是否被截断（复制时丢了尾部字符）
- 用脚本生成的 URL 一定做过自检（解压必须与原文逐字节相同），手改 URL 则可能坏

### 链接太长发不出去？

改用 `--out` 出分享页，或 `bundle-single` 出单文件。

### 能不能自定义分享的站点域名？

```bash
node tools/ext.mjs share --circuit lrc --base https://你的域名/子路径
```
或用环境变量 `EXC_SHARE_BASE`。

### 分享的电路包含仿真状态吗？

**不包含**。`ctz` 只含电路本身（元件、参数、坐标、导线），不含当前时间和元件状态。对方打开是 t=0 的初始状态——这通常是想要的行为。

### 可以在链接里带主题/插件配置吗？

不能。分享链接只承载电路。主题等外观设置是各人本地的 `localStorage`。
