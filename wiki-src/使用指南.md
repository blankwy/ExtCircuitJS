# ExtCircuitJS 使用指南

ExtCircuitJS 是基于 [CircuitJS1](https://github.com/pfalstad/circuitjs1) 的二开版电路仿真器：保留上游全部仿真与绘图能力，在其上叠加了**网表读写**、**网表→电路编译器**、**MCP 服务**（让 AI 直接操作电路）与**插件系统**。

> 本文面向使用者。开发与插件开发见 [开发指南](开发指南) 与 [插件开发](插件开发)。
> 上游基线：`e952e78` / `5.0.3ts`（全 TypeScript + Vite）。许可证 GPL-2.0-or-later。

## 第一次运行

### 环境要求

- **Node.js ≥ 22**（`node --version` 检查）
- 现代浏览器（Chrome / Edge / Firefox / Safari）

### 启动

```bash
git clone https://github.com/blankwy/ExtCircuitJS.git
cd ExtCircuitJS

npm install --prefix core/ts     # 安装上游依赖（Vite/TypeScript 等）
node tools/ext.mjs build         # 构建到 dist/
node tools/ext.mjs serve         # 起本地服务，浏览器打开 http://127.0.0.1:8080/
```

> **为什么不能双击 `dist/index.html`？**
> 产物是 ES module（`<script type="module">`），浏览器禁止在 `file://` 协议下加载模块（CORS 白名单只含 http/https 等），
> 会报 `Access to script ... from origin 'null' has been blocked by CORS policy`。**这不是 bug，所有 Vite 项目都如此**，必须走 http。
> `ext serve` 就是为此准备的零依赖静态服务器（`--port` 可改端口）。

### 开发模式（带热更新）

```bash
node tools/ext.mjs dev --port 5174   # 改 cover/ 与 core/ts 的源码会热更新
```

## 核心功能

### 绘制与仿真（沿用上游）

点击工具栏元件 → 在画布上拖放。空格键或 RUN 按钮启动仿真。上游所有功能（子电路、示波器、DC 分析、导入导出等）都可用。

### 网表读写（AI 与程序接口）

`window.ExtCircuitJS.api` 暴露了结构化接口，浏览器控制台可直接试：

```js
const ext = window.ExtCircuitJS;

ext.api.dumpNetlist();                          // 语义网表（JSON）
ext.api.listComponents();                       // 元件清单（含稳定 id）
ext.api.applyOps([                              // 补丁式写：改参数
  { op: "set", target: "e1", prop: "resistance", value: 2200 }
]);
ext.api.getMeasurements();                      // 节点电压 + 元件电流
await ext.plugins.reload("hello");              // 插件热重载
```

三种格式的分工：

| 用途 | 格式 |
|---|---|
| 存档 / 与上游互操作 | 官方 XML（不变） |
| AI 读（理解、推理） | 语义 JSON（`netlist/0.1`） |
| AI 读（省 token） | 紧凑 JSON（约 0.26× XML） |

**稳定 id**：网表里的元件 id 形如 `e1`、`e2`，编辑后未受影响的元件 id 不变（删除不会让后续 id 前移）。

### 网表 → 电路编译器

给一份网表 JSON（可以没有坐标），自动布局 + A* 绕障布线，重建出可运行的电路，并用**拓扑硬闸**校验（引脚分组不一致就回滚拒绝）。

```js
// 载入网表 JSON（命名或紧凑格式都行）
ext.api.loadNetlist(JSON.stringify(netlist));
```

## 让 AI 操作电路（MCP）

MCP（Model Context Protocol）让 Claude 等 AI 助手直接读写你的电路。

```bash
node tools/ext.mjs mcp     # 启动 stdio MCP 服务器
```

在 MCP 宿主（如 Claude Desktop）配置里加：

```json
{
  "mcpServers": {
    "extcircuitjs": {
      "command": "node",
      "args": ["/绝对路径/ExtCircuitJS/tools/ext.mjs", "mcp"]
    }
  }
}
```

服务器会自管后端（探活 dev server，不可达就拉起；headless Chrome 打开页面）。

**可用工具**：

| 工具 | 作用 |
|---|---|
| `circuit.get_netlist` | 读网表（`format=compact` 可要紧凑格式） |
| `circuit.load_netlist` | 载入电路文本 / XML / 网表 JSON |
| `circuit.list_components` | 元件清单 |
| `circuit.set_param` | 改元件参数 |
| `sim.run` / `sim.stop` | 启动 / 暂停实时仿真 |
| `sim.step` | 确定性步进（读数可复现） |
| `sim.reset` | 复位 |
| `sim.read_measurements` | 读瞬时电压/电流 |
| `sim.read_scope` | 读示波器波形 |
| `schematic.screenshot` | 截图 |

详细说明见仓库 `docs/mcp.md`。

## 插件管理

### 配置启停

编辑 `cover/site.config.json`：

```json
{
  "plugins": {
    "disabled": ["ext-panel", "ext-command", "ext-event", "ext-hook", "ext-element"]
  }
}
```

- `disabled` 列出的插件**不会自动加载**（部署侧语义），但它们仍在 `plugins/` 里，可随时从列表移除来启用。
- 定义在 `plugins/plugins.manifest.json` 的 `enabled: false` 同理（插件自带的默认开关）。
- 两者取交集：**两边都放行才会自动加载**。
- 显式调用 `ext.plugins.activate(id)` 不受此限制。

改完 `site.config.json` 后重新 `build`（或 dev 下直接刷新）。

### 当前自带的插件

| 插件 | 默认 | 说明 |
|---|---|---|
| `hello` | 开 | 最小示例：面板 + 命令 + 事件订阅，用来验证插件系统 |
| `ext-theme` | 开 | **UI 外观**：选项菜单里切换深色/浅色 |
| `ext-neumorph` | 开 | **新拟态主题**：软阴影浮雕风格，选项菜单可开关 |
| `ext-panel` | 关 | 示例：侧栏面板插槽 |
| `ext-command` | 关 | 示例：命令面板插槽 |
| `ext-event` | 关 | 示例：事件订阅（analyze / elementschange / elemdrag） |
| `ext-hook` | 关 | 示例：打开/保存钩子（可改写存档文本） |
| `ext-element` | 关 | 示例：注册自定义元件（类 + 存档类型 + 菜单） |
| `ext-worker` | 关 | 示例：Worker 模式插件（隔离运行，postMessage RPC） |

> 示例插件默认关闭，是为了让界面干净；它们是**开发参考**，读它们的源码是学插件开发的最快路径。
> 内置插件的详细功能说明见 [内置插件](内置插件)。

## 外观与主题

### 深色 / 浅色切换

【选项】菜单 → **UI 外观**：点击在深色/浅色间切换。

- **深色**：深色 UI 外壳 + 画布黑底白线
- **浅色**：默认外壳 + 画布白底黑线（复用上游的 White Background 开关）
- 选择会记住（下次打开自动恢复）

### 新拟态风格

【选项】菜单 → **新拟态样式**：默认开启。软阴影、圆角、同色系浮雕（底 `#e0e5ec`）。

只改样式**不改布局**，画布会自动切到白底配合。想关掉就是再点一次。

### 关于页

编辑 `cover/site.config.json` 的 `about` 段可自定义：

```json
{
  "about": {
    "heading": "关于 ExtCircuitJS",
    "html": "<p>你的说明文字（支持 HTML）</p>"
  }
}
```

自定义内容会插到上游 about 页最前面，**GPL 许可声明按许可证要求原样保留在下方**。

同文件还能改 `title`（浏览器标题基名）、`htmlTitle`（静态标题）、`description`（SEO 描述）、`homeurl`（关于页的返回主页链接）。

## 常见问题

### 双击 index.html 打不开 / 控制台报 CORS

见上文 [第一次运行](#第一次运行) —— ES module 不能走 `file://`，用 `node tools/ext.mjs serve`。

### 界面没有我期待的新功能？

核心扩展（网表、编译器、MCP、插件系统）是**给程序和 AI 用的接口**，不是界面按钮；多数示例插件默认关闭以免界面杂乱。
先在浏览器控制台试 `window.ExtCircuitJS.api.dumpNetlist()`，或看 [内置插件](内置插件) 里开了哪些可视化功能。

### 元件参数改了但仿真没变化？

改完参数后仿真需要重新分析：`applyOps` 会自动触发；手动改则点 Reset 或空格键重启仿真。

### dev server 端口被占用

```bash
node tools/ext.mjs dev --port 5180     # 换端口
node tools/ext.mjs serve --port 8081
```

### 想看构建产物是否正常

```bash
node tests/contract/dist-site.browser.mjs   # 把 dist/ 当站点打开做端到端验证（需 dev server）
```
